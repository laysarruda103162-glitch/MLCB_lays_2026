# AC-1 - Machine Learning & Chatbots

## Classificador de Sentimentos

Nesta atividade foi desenvolvido um classificador supervisionado de sentimentos utilizando Machine Learning.

O objetivo é classificar frases como positivas ou negativas.

### Etapas do projeto

1. Entrada dos textos
2. Vetorização utilizando CountVectorizer (Bag of Words)
3. Treinamento utilizando Multinomial Naive Bayes
4. Predição de novos textos
5. Avaliação do modelo

### Tecnologias utilizadas

- Python
- Scikit-learn
- Google Colab
- GitHub
